# 奶娃森林冰火人

一个模仿《森林冰火人》（Fireboy & Watergirl）玩法的**双人合作闯关小游戏**，主角换成了你提供的奶娃照片（照片里的两人已分别抠图成两个角色）。

## 怎么玩

1. 双击打开 `index.html`（无需安装、无需联网）。
2. 让**火娃**和**水娃**都走到右边的**木门**前站上去，并且**收齐本关全部物品**即过关，进入下一关。

### 核心规则（与森林冰火人一致）

- 水娃能走**水**（蓝色水池），火娃能走**火**（橙色岩浆）。
- 火娃踩到水会死，水娃踩到岩浆会死。
- **绿地（酸液）** 和 **尖刺** 两个人都不能踩。
- **任一人死亡，本关整体重开**（人物、物品全部复位）。
- 走到地图最左/最右边缘会被边界挡住，不会掉下去。

### 物品规则

- 💧 水娃要喝**珍珠奶茶**（`T`），吃不了汉堡。
- 🔥 火娃要吃**汉堡**（`B`），喝不了奶茶。
- 两个人各收各的，收齐物品 + 同时到门口才算过关。

### 操作（同一键盘双人）

| 角色 | 移动 | 跳跃 |
|------|------|------|
| 🔥 火娃 | `A` `D` | `W` |
| 💧 水娃 | `←` `→` | `↑` |

> 提示：同时按「移动 + 跳」没反应，多半是键盘按键冲突（键位 ghosting），可换个键盘或在系统里调整键位。本作已优化按键手感，支持跳跃缓冲与离台宽限，操作更跟手。

## 文件结构

```
index.html        页面入口
style.css         页面样式
game.js           游戏主逻辑（物理/渲染/关卡流程）
levels.js         关卡数据（字符网格，可自行加关）
assets/
  fire_baby.png   火娃（抠图后，透明背景）
  water_baby.png  水娃（抠图后，透明背景）
tools/
  extract.mjs     一次性抠图脚本（@imgly 去背景）
  split.mjs       分离两人的脚本
  finalize.mjs    缩放成游戏用尺寸
README.md
```

## 怎么改关卡 / 换角色

- **加关卡**：编辑 `levels.js`，复制一个关卡数组，按图例字符改地图即可。图例见文件顶部注释。
- **换角色**：把新的两张透明 PNG 放到 `assets/` 覆盖 `fire_baby.png`、`water_baby.png`（建议竖长身形、透明背景）。若想重新从照片抠图，修改 `tools/extract.mjs` 里的输入文件名后运行 `node tools/extract.mjs`。
- **对调火/水身份**：编辑 `game.js` 顶部 `ASSETS` 里 `fire` / `water` 对应的图片文件名即可。
